Learning Journey

Village Schools International

December 2025 (Yearly Improvement)

Annual Turnover Process

Closing and Preserving 2025 Systems - Opening and Releasing 2026 Systems

Problem:
Original (2022) Methods required manually inspecting and closing out every school file within Village Schools. As Village Schools expanded, this annoyance became an administrative nightmare - delaying the release of new year files and financial audit reports.
Approach:
Step by Step Automation, G.A.S. custom menus for automating aspects of the process. Each year improved as needs changed.
Takeaways:
Interviewing and understanding true painpoints is an invaluable skill in a growing organization. Prioritizing tasks that grow in pain as the organization scales is crucial. Implementing automation - while useful - is not always (immediately) necessary.
Notes:
This system had to be anonymized prior to making it available. I copied my code and placed it into it's own file - this way it is unbounded and not tied to any confidential work.
