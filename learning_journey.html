What I'm learning at Epitech

Pool by pool: what each sprint covered, and what actually stuck.

Epitech Paris (DIT)

September 21 – October 4, 2026

Python Pre-Pool

Pre-Pool designed to introduce students to programmatic thinking

Skill summary
Over ten days of the Epitech Pre-Pool, this work builds foundational developer skills, starting with the shell, file and folder management, the Vim, Emacs and nano editors, and Git version control. It then progresses through core Python, covering variables, loops, conditionals, comparison and arithmetic operators, string handling, lists, functions, recursion, user input, and command-line arguments, with timed challenges comparing approaches such as built-in sort versus bubble and merge sort, or operator-based versus recursive power functions. The final days apply those fundamentals to a complete Hangman project, extending it with word categories, a guessing bot, a high-score leaderboard, a Pygame graphical interface, external libraries managed through requirements files, and packaging into a standalone executable with PyInstaller.
Takeaways
The biggest lesson is that fluency with everyday tools such as the terminal, Git, and a text editor matters as much as the code itself, since every later task depended on them. The Python challenges showed that measuring performance beats guessing, as the timed comparisons made clear how much algorithm choice and built-in functions affect speed. Finally, the Hangman project demonstrated that a small program grows into a real application through incremental additions like file-based data, a bot opponent, a graphical interface, and packaging for distribution.

October 5 – October 18, 2026

Web Development Pool

First Pool Introducing Students to Bash, HTML, CSS, JS, AJAX, and PHP

Skill summary
Over ten days of the Epitech Web Bootcamp, this work moves from Bash scripting for file creation, searching, batch replacement, backups, and directory automation into the core front-end stack of semantic HTML, CSS styling, and the Materialize framework. It then covers JavaScript in two settings: Node modules with tester files for functions like range and array utilities, and browser scripting with DOM selection, event listeners, drag events, and a keyboard-driven sprite animation on the multi-page digital resume. The final days add the back end with PHP functions, query-string routing and dynamic page bodies, SQLite through PDO with prepared statements, SQL queries for selecting, filtering, inserting, updating, and deleting, and AJAX form validation that returns JSON from PHP to a JavaScript front end, applied again in a hike-logging practice project.
Takeaways
The clearest lesson is how the full request cycle fits together: a form in the browser, JavaScript sending the request, PHP validating input and querying a database, and JSON coming back to update the page without a reload. Validation on the server side, with prepared statements and explicit error responses, proved just as important as the visible interface. Finally, the resume project and the extra practice folder show that reusing a framework and revisiting earlier work with new tools is where the individual skills turned into something usable. Much of what I learned was used in making this portfolio!
