Village Schools International · 2026

Master Information & Analytics System

One scalable source of truth for 19,000+ student records.

March 2026

Aggregating all information for ease of validation and analysis

Problem
As Village Schools scaled, systems started timing out and many users creating custom spreadsheets led to complicated webs of dependencies.
Approach
Step back and recognize the current system was bloated. Identify key factors that led to that. Redesign System from ground-up with "scalability" as the primary focus.
Takeaways
Just because "this is the way we've done it" doesn't mean that "this is the way we should still do it". A full redesign is important. Build parallel systems in discrete, testable, and integratable chunks.
Notes
This system had to be anonymized prior to making it available. I copied my code and placed it into its own file - this way it is unbounded and not tied to any confidential work.
